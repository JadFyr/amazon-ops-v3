## 2. 知识点条目（入库原始料）

> 编号规则 `M<模块>-<序号>`；每条含【口径】【可出题点】【来源】。
> 来源角标：`[概况]`=基础知识概况 · `[笔记]`=运营运营基础docx · `[橙子]`=运营题.txt · `[xls]`=运营题库.xls · `[既有]`=系统已有

### M1 平台概念与账号规则

**M1-01 编码体系**
- 口径：SKU=卖家自定义编号；ASIN=亚马逊分配的唯一商品编号（10 位）；FNSKU=FBA 仓库识别条码；UPC/EAN=商品条码（无品牌备案时必填）`[概况]`
- 可出题点：给一个「同一产品多颜色变体」的场景，问哪个标识在变体间共享、哪个不共享（ASIN 按变体拆分、FNSKU 每个 SKU 独立、父体无 FNSKU）

**M1-02 履约方式**
- 口径：FBA=仓储+配送+客服全包，带 Prime 标；FBM=自发货，适合大件/低周转 `[概况]`
- 可出题点：大件家具、季节性慢周转品该选哪个；FBA 断货时能否临时切 FBM 保链接（能，但会影响 Buy Box 与配送时效评分）

**M1-03 Buy Box**
- 口径：赢得 Buy Box 才能拿到大部分订单，受价格、配送方式、库存、绩效影响 `[概况]`
- 可出题点：跟卖场景下「价格更低但没拿购物车」的排查顺序（配送方式→库存→绩效→价格）

**M1-04 卖家类型差异**
- 口径：个人卖家 vs 专业卖家**佣金比例完全相同**；差别在月租、批量上架权限、促销报名权限（进一步：SB/SD 与 A+ 需品牌备案，个人卖家实际不具备）`[xls]`
- 可出题点：这是 xls 里唯一一道「陷阱设在『不包括』」的题，保留价值在于反直觉；但要补上「品牌备案权限」这层，否则答对也讲不深

**M1-05 账号绩效指标**
- 口径：ODR < 1%；LSR（迟发率）< 4%；VTR（有效追踪率）> 95%；取消率 < 2.5%；AHR=账号健康评级 `[概况]`+`[既有]`
- 可出题点：给 4 个指标数字，问「哪一个是立刻会触发审核的」（ODR 越过 1%）
- ⚠️ 口径提示：「迟发率 4%」在部分类目写作 LSR<4%，与「取消率<2.5%」是两条不同指标，出题时不可混用

**M1-06 Listing 违规敏感词**
- 口径：Non-slip、Anti-Fouling、Easy cleaning、Heat-resistant、Flame retardancy、Wear-resisting、Not easy to fade、Anti-Mites、Inhibit-Algae、Anti-Bacteria、Stop-Microbe/Mildew、Destroy Fungal、Repel-Pesticides、antifungal、Sanitize-Blight、Sterilize、Insect prevention、Resistant for mosquitoes & ants 等，属「功效/医疗/杀虫」类高风险词根 `[橙子]`
- 可出题点：保温杯写 "Anti-Bacteria Liner" 该改成什么（→ "Easy-clean liner / BPA-Free"）；这是**真实高频下架原因**，比考定义有价值

**M1-07 认证门槛**
- 口径：FCC、UL、FDA、CPC、PSE、TELEC、PSC、CE、CE-RED、RoHS、WEEE `[橙子]`
- 可出题点：只考「哪类产品需要 CPC」（儿童用品），不考清单默写——清单属于查得到的知识

### M2 关键词运营 ← 本批新增最有价值模块

**M2-01 收集阶段的量**
- 口径：初期尽量多收集，多插件 + 竞品 ASIN 反查 + 词根统计表 `[笔记]`
- 可出题点：竞品反查导出 800 个词，第一步做什么（→ 做减法剔除不匹配，而不是直接挑词投放）

**M2-02 分级三法（核心）**
- 口径：
  1. **搜索排名法**（竞争大类）：5 万名内=一级，5 万–10 万=二级
  2. **流量占比法**（关键词仅 200–300 个的小类目）：占比 30%–10%=一级，10%–1%=二级；实践中一级到二级常有断崖（如 21%/15%/12% 之后直接跌到 5%）
  3. **竞品交叉法**：分析多个头部竞品，找共性词
- 可出题点：★ 给一组 6 个词的流量占比（21/15/12/5/3/1），问「一级核心词该切几个」——考的是识别断崖，不是套公式
- ⚠️ 阈值是**经验值不是标准**，出题时必须写「某类目经验分层」，禁止表述为行业统一标准

**M2-03 分级必须围绕相关性（反例题）**
- 口径：砧板类目里「厨房用品」流量比核心词「砧板」更大，但范围太泛，**不能做一级核心词**；分级要围绕主要用途、主要功能取舍 `[笔记]`
- 可出题点：★★ 这是全批最好的一个反例，天然构成「流量大 ≠ 该做核心词」的单选题，且能延伸到广告里的大词要不要否

**M2-04 入场词级选择**
- 口径：竞争大类，企业卖家从二/三级词入场；个人卖家从三级词入场；竞争小类目有实力者可一级词直接入场 `[笔记]`
- 可出题点：与「新品冷启动该不该直接打大词」联动，考取舍

**M2-05 埋词权重顺序**
- 口径：**标题 > 五点 > 详情 > ST**（后台 Search Terms 权重最低）`[笔记]`+`[既有]`
- 可出题点：同一个词该优先放哪个字段；ST 是否值得为埋词牺牲可读性（不值得）

**M2-06 埋词三原则**
- 口径：①重要词放前面（标题开头、五点每条开头）②语句通顺符合目标国阅读习惯 ③满足前两条前提下尽量多次埋入，但五点不要为埋词写空洞内容 `[笔记]`
- 可出题点：给一段「关键词密度很高但读不通」的五点，问问题在哪

**M2-07 埋词重复的两种流派（不能当标准答案）**
- 口径：一说「重复出现加权」，一说「同一 Listing 内只抓一次」。**无官方定论** `[笔记]`
- 处理：只在简答题里出现，作为「你怎么验证一个没有定论的说法」的考察点，**绝不作为选择题正确项**

**M2-08 否词时机（最容易被答错的一条）**
- 口径：
  - 文案阶段先埋好，不精准流量本来就进不来
  - 竞争度小的类目，前期几乎不需要否词；成熟后只否「高点击低转化」的少数词
  - 竞争大的类目，核心大词像个**加速开关**：要判断基本面（Listing/控评）能不能接住、预算经不经得住烧
  - 一般类目：前期先否大词，等点击转化理想后释放；小众类目不必否大词
  - **否掉后销量下滑 → 立刻把词拉回来** `[笔记]`
- 可出题点：★★★ 「新品第 2 周，大词花了 $180、12 次点击、0 单，要不要否？」正解是分情况（预算能否承受 + 是否已测出点击率），不是一刀切
- ⚠️ 与既有纪律「数据量不够不否」的关系：见 §3-4 的调和说明，**这两条必须成对出题**，否则会互相打脸

### M3 Listing 文案

**M3-01 标题公式**
- 口径：品牌 + 产品名/型号/类型 + 关键词 + 适用范围（用途/卖点）+ 产品属性（颜色/尺寸）；**至少埋 3 个关键词 + 3 个卖点**；不能为堆词牺牲通顺 `[笔记]`
- 可出题点：给 3 个候选人写的标题，问哪个最可能被点开（考「可读性 vs 关键词密度」的取舍）

**M3-02 标题字符上限**
- 口径：北美多数类目 ≤200 字符 `[概况]`+`[既有]`
- ⚠️ 类目差异大（部分类目 80 / 150），出题时写「多数类目」并加 caveat，不写死

**M3-03 标题的「模式识别」方法**
- 口径：观察小类前 50 名竞品标题的构成要素，先识别模式，再套写；不是抄一条 `[笔记]`
- 可出题点：新人直接抄竞品标题的三个后果（重合度过高、新链接打不过老链接、可能带入他人品牌词）

**M3-04 五点排序方法论（可操作，非口号）**
- 口径：前 3 条放最打动客户的点；**如果拿不准哪 3 条最打动客户 → 取小类前 10 个同类竞品，统计其前 3 条写什么，按出现频次排序**；5 条为宜，单条不冗长 `[笔记]`
- 可出题点：★★ 这是把「凭感觉写文案」变成「有方法可复用」的关键一条，适合做简答评分要点

**M3-05 五点客户视角四问**
- 口径：①是否解答购买顾虑 ②是否简洁 ③是否可读 ④是否埋入关键词 `[笔记]`
- 可出题点：给一段五点，问最该先改哪一条（通常是最长且没有解决顾虑的那条）

**M3-06 详情页的两种分工**
- 口径：**有 A+** → 客户看不到详情文案，详情页侧重埋词（严禁出现竞品品牌）；**无 A+** → 详情页承接五点做细节/功能/参数展开，以打消顾虑为主，不是堆词 `[笔记]`
- 可出题点：★★ 「已上 A+，还要不要在详情里堆关键词」——正解是要，但目的变了（权重 vs 转化）

**M3-07 A+ 转化率**
- 口径：资料称「配置 A+ 的 Listing 转化率比未配置高 8%」`[笔记]`
- ⚠️ 无出处，**出题不写具体数字**，只说「A+ 通常带来可测的转化提升」

**M3-08 COSMO 算法影响**
- 口径：COSMO 加强「人物画像 + 使用场景」权重，写 Listing 时要把场景因素写进去 `[笔记]`
- 可出题点：同一个保温杯，「500ml 不锈钢」vs「通勤族早八装咖啡不漏」哪个更吃新算法

### M4 图片运营（本批意外收获，全是实操细节）

**M4-01 格式与像素**
- 口径：**只用 JPG**；主图 1600×1600；移动端可 1:1.2 或 3:4；A+ 图按亚马逊建议最低像素（带文字标准图 970×600），**放大 3–5 倍上传前端口仍按 970×600 显示，反而噪点更多、加载更慢** `[笔记]`
- 可出题点：★★ 设计师交来 2900×1800 的 A+ 图，该不该直接用（不该）——这是一个「反直觉但可验证」的经验，面试讲出来很占便宜

**M4-02 少字多特写**
- 口径：按最低像素做图会导致小字糊，所以**图内文案要少、尽量放产品部位特写** `[笔记]`
- 可出题点：A+ 图上放 200 字卖点文案的问题（手机屏看不清）

**M4-03 手机端 / 电脑端优先级判断（有数据路径，可考）**
- 口径：业务报告 → SKU 绩效 → 对比「会话-移动应用」与「会话-浏览器」 → 手机端占比高则优先优化手机端（主图 1:1.2 或 3:4），电脑端占优则用 1:1
- 经验判断：低货值标品优先手机端；高货值/重决策（婴儿车、仪器、吃评论的产品）优先电脑端 `[笔记]`
- 可出题点：★★★ 这条把「我觉得手机上好看」变成了「我去拉哪个报表的哪两个字段」，是典型的运营 vs 助理分界

**M4-04 主图与附图逻辑**
- 口径：首图核心指标=**点击率**；按目标市场审美调整（欧美偏简约个性）；建议以 1 个月为周期测不同首图 CTR。附图按客户关注度排序（卖扳手 → 前三张放参数/材质/配件，差异化赠品放附一图） `[笔记]`
- 可出题点：CTR 低时，先换主图还是先改标题（先主图，但要用 A/B 或同周期对比，不能同周双动）

**M4-05 A+ 排版总-分-总**
- 口径：首模块=LOGO + 产品总介绍图 → 再按客户关注点展开（不同产品关注点不同：材料 / 功率 / 尺寸） `[笔记]`
- 可出题点：A+ 第一屏该放什么（不是放 5 个卖点图标，是先给「这是什么」）

### M5 广告与 ACOS 决策

**M5-01 可接受 ACOS 的两层含义（xls 里质量最高的一道）**
- 口径：广告前毛利 = 售价 − 成本 − FBA − 佣金 → 广告前毛利率 = 毛利/售价。**盈亏平衡 ACOS = 广告前毛利率**；**带利润要求的可接受 ACOS = 广告前毛利率 − 目标净利率**
- 算例：售价 $30、成本 $12、FBA+佣金 $8 → 毛利 $10 → 33.3%；目标净利 15% → 广告费上限 $30×(33.3%−15%)=$5.5 → **ACOS 18.3%** `[xls]`
- 可出题点：★★★ 升级为 3 空填空：广告前毛利 / 可承受广告费 / 可接受 ACOS；再追问「如果只答 33.3%，错在哪」（混淆盈亏平衡线）

**M5-02 异常排查顺序**
- 口径：先分层定位（点击端 / 转化端 / 成本端）→ 拉搜索词报告看泛词占比 → 看 CTR/CVR 变化 → 再决定否词 / 降 bid / 改 Listing。**不要第一步关广告或全盘降 bid** `[xls]`+`[既有]`
- 可出题点：与系统模拟 A 的第 1 步同源，此处只做「短平快」的选择题补充

**M5-03 高曝光低 CTR 的优先级**
- 口径：自动广告 4 周、曝光高、CTR 0.2%、ACOS 60% → **矛盾在点击端**（CTR 远低于 0.3%），动作优先级：否掉高花费 0 转化泛词 → 查主图/标题/价格 → 降自动出价。**不要先改详情页，流量本身就不精准** `[xls]`
- 可出题点：★★★★ 这是全批最好的一道场景题，直接可入库（只需把 0.3% 补上「3C/杯壶参考值」）

**M5-04 TACOS 降而 ACOS 升**
- 口径：可能原因 ①自然流量转化增多，TACOS 被摊薄 ②自然转化提高但广告点击多为非意图流量（广告效率变差）`[xls]`
- 可出题点：★★ 多选题，考「两个指标背离时不必然是好消息」，与既有「趋势比绝对值重要」互补

**M5-05 成熟 ASIN 控 ACOS**
- 口径：集中预算于高转化精准词；提高自动出价会扩大泛流量；加投竞品不一定能控成本 `[xls]`
- 可出题点：与生命周期阶段（成熟期保利润）联动

**M5-06 广告前提**
- 口径：Listing 到位、至少 5 条以上好评、有 Buy Box `[概况]`
- ⚠️ 同一文档写「CTR>0.5%、CR>15%」作为前提线，与本次裁决的 3C/杯壶口径（CTR 0.3–0.5%、CVR 4.5–9.5%）冲突 → 按 §4-2 处理

### M6 库存与补货

**M6-01 补货量（已裁决）**
- 口径：`补货量 = 日均销量 × 总周期 + 安全库存 − 当前总库存`；`总周期 = 采购 + 头程 + 入仓缓冲`；`安全库存 = 日均 × 总周期 × 系数`（海运 1.2 / 空运 1.0–1.1）`[既有]`+`[xls]`
- 算例：日均 20、采购 30 + 头程 25 + 缓冲 10 = 65 天、系数 1.2、总库存 800 → 安全库存 1560 → 补货 1300 + 1560 − 800 = **2060 件**

**M6-02 补货触发条件**
- 口径：现有库存可支撑月数 **≤** 备货总周期时必须下单 `[xls]`
- ⚠️ 原文写「等于」，正确表述是「小于等于」；出题按 ≤

**M6-03 日均销量口径**
- 口径：`近 7 天×70% + 近 30 天×30%`（短期权重更高，兼顾平滑）`[既有]`
- 可出题点：为什么不是简单取 30 天平均（促销/断货会失真）

**M6-04 周转与仓储**
- 口径：周转天数 30–60 天；IPI < 400 被限仓；超 365 天库存仓储费极高，清货优先级应高于「再多卖几个」`[既有]`

**M6-05 断货的真实代价**
- 口径：不只是缺货损失，还有排名恢复所需的广告成本；判断空运的唯一依据=剩余可售天数 < 补货总时长 `[既有]`

### M7 选品与生命周期

**M7-01 类目可进入性三验**
- 口径：不是看销量大，而是 ①需求是否持续（搜索趋势）②竞争是否可进入（头部评论壁垒）③利润是否扛得住全成本（含广告与退货）。Top10 全是万级评论品牌时，同款低价进场没有胜算 `[xls]`
- 可出题点：★ 给一组「月销 3000 单、Top10 平均 8000 评论、净利 6%」的数据，问该不该进（三个红灯全亮）

**M7-02 差评 → 产品定义 + Listing + 广告**
- 口径：差评主题 → 产品端改进（成本允许时）→ Listing 主动回应痛点（标题/五点/QA）→ 把痛点词做成精准投放词 `[xls]`+`[既有 Owala 项目]`
- 可出题点：★★★★ 这是把「会看差评」变成「三处落地动作」的题，与用户的 Owala 项目直接呼应，是作品集与测评的连接点

**M7-03 资金分配与止损**
- 口径：10 万选 3 个 SKU 的高分回答含 ①先划可承受试错成本 ②每 SKU 四维验证（需求/竞争/利润/合规）③不押单品 ④明确止损线 `[xls]`

**M7-04 三类应淘汰的机会**
- 口径：有销量没利润 / 有利润做不大 / 能做但合规风险高 `[既有]`

### M8 面试防坑（不计分，仅简答素材）

> 定位：**知道但不做**。用于回答主管「你怎么看刷单/跟卖/黑科技」，展示边界感而不是操作能力。

**M8-01 跟卖与反跟卖**
- 口径：反跟卖工具链 = 品牌备案 + 透明计划 + Test Buy + 举报；「找客服写投诉信赶跟卖」存在反噬风险（自身合规瑕疵被翻出）`[橙子]`

**M8-02 常见黑科技与风险**
- 口径：突破发货限制（风险：货件被取消）、改标题/资料（风险不明）、站外 FB 群组放量（风险：转化率下降、被识别为操纵）`[橙子]`

**M8-03 测评 / 直评 / 跟卖上评**
- 口径：平台明令禁止；沙龙式「低价螺旋 + 测评」在当前环境下属**高风险路径**，不是可推荐的运营手法 `[橙子]`

**M8-04 竞品攻击手段清单**
- 口径：差评、恶意点赞、刷好评、敏感词投诉、邮件轰炸、买断库存、跟卖、改类目、虚假投诉、虚假 QA、盗用商标 `[橙子]`
- 可出题点：作为简答「你如何识别一次销量下滑是市场原因还是被攻击」的答题素材

**M8-05 服务商资源与原理**
- 口径：服务商本质卖的是「账号资源 + 信息差 + 灰色操作通道」；面试标准答法是「知道存在，但公司层面不依赖」`[橙子]`

**M8-06 大卖 vs 小麦套路（认知题）**
- 口径：大卖=社媒粉丝池+广告+测评+合并评论+小号跟卖；小麦=低价螺旋+小广告+测评+站外折扣 `[橙子]`
- 处理：**只保留「低价螺旋」和「站外折扣」作为合法手段讲**，其余标注为高风险/违规，避免把违规操作当成「运营套路」背下来

### 3-4 关键调和：「数据量不够不否」vs「先验不相关立即否」

这两条看似矛盾，必须一起讲才立得住：

- **先验不相关**（材质 / 类型 / 品类完全不符，如保温杯里的 plastic bottle、disposable cup）→ **不需要数据量，立即否**。理由：它永远不可能转化，多花一天就是纯浪费。
- **有相关性但数据不足**（如某个「保温杯 保冷」长尾词花了 $6、2 次点击、0 单）→ **不能否**。理由：2 次点击的 0 单是统计噪音，否掉可能杀掉一个未来的好词。
- 判据一句话：**「这个词有没有可能成交」先看语义，再谈数据量**。
